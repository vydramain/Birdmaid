# Правила Cursor

Правила Cursor действуют как системные инструкции для Agent/Composer (единые стандарты качества/стиля/DoD).

## Структура правил

| Файл | Описание |
|------|----------|
| [product-delivery.md](./product-delivery.md) | Базовые правила для product delivery (из описания агентов) |
| [agent-workflow.md](./agent-workflow.md) | Правила для работы с агентами и workflow-ролями |
| [agents.md](./agents.md) | Интеграция агентов в Cursor (как использовать @AgentName) |

## Как использовать

Эти правила автоматически применяются Cursor при работе с Agent/Composer. Они обеспечивают единые стандарты качества и стиля работы.

## Связь с другими документами

- **AGENTS.md** — главный документ с правилами workflow
- **ai/roles/** — workflow-роли, которые следуют этим правилам
- **ai/agents/** — агенты-специалисты, которые могут использоваться в workflow
