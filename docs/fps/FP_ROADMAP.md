# Feature Packs Roadmap: Windows93-style Platform

**Цель:** Преобразовать платформу Birdmaid в псевдо-ОС в стиле Windows93 с практической функцией архива для Омского гейм-дев сообщества.

**Референс:** [Windows93.net](https://www.windows93.net/)

---

## Текущее состояние (FP1-FP5)

### ✅ FP1: Browse & Play + Admin Authoring (release)
- Публичный каталог игр
- Админка для создания команд, игр, загрузки билдов
- Публикация игр, теги, статусы

### ✅ FP2: Team System and Game Editing (release)
- Улучшенная система команд
- Валидация и обработка ошибок

### ✅ FP3: Windows 95 UI Behavior (release)
- CSP middleware
- Подготовка к Windows 95 UI

### ✅ FP4: User Accounts & Windows 95 UI (release)
- Система пользователей (email/username, password recovery)
- Windows 95 стилизация (частично)
- Комментарии к играм
- Управление командами

### ✅ FP5: UI/UX Fixes and Polish (release)
- Исправления UI/UX
- Windows 95 стилизация компонентов

---

## Планируемые Feature Packs (FP6-FP15)

### 🎯 FP6: Desktop Workspace & Window Manager (plan)
**Статус:** В разработке scope

**Что входит:**
- Desktop "Рабочий стол" с иконками
- Window Manager (открытие/закрытие/фокус окон)
- Windows Mobile режим
- Explorer (базовая версия)
- HELP.TXT
- "Говно - не открывать"

**Приоритет:** Высокий (основа для Windows93-стиля)

**Зависимости:** FP4 (Windows 95 UI компоненты)

---

### 📁 FP7: Explorer & Media Viewers (Performance & VFS)
**Статус:** design
**Что входит:**
- Unified Shell (Architecture Refactor)
- Performance Budget (Zero-Lag Drag)
- Full Explorer (Tree + Grid)
- Media Viewers (Image, Video, Text)
- VFS (Event-driven)

**Приоритет:** Высокий (Performance Foundation)

**Зависимости:** FP6 (базовый Explorer)

---

### 🎮 FP8: "Безделушки" & Micro-interactions (todo)
**Что входит:**
- Интерактивные мини-приложения
- Мини-игры
- Визуальные эффекты (анимации, глитчи)
- Звуки интерфейса (опционально)
- Пасхалки

**Приоритет:** Средний (атмосфера, delighters)

**Зависимости:** FP6 (Window Manager)

---

### 🎪 FP9: Jam Info & Registration Wizard (todo)
**Что входит:**
- Инфо-раздел "Джем" (окно с frame, вирус-вымогатель стиль)
- Отсчёт времени до джема
- "Мастер по установке" для регистрации на джем
- Поэтапная форма регистрации
- Лицензионное соглашение (юзер продаёт душу)

**Приоритет:** Средний (для участников джемов)

**Зависимости:** FP6 (Window Manager), FP4 (авторизация)

---

### 🔐 FP10: Telegram Auth & Registration Wizard (todo)
**Что входит:**
- Авторизация через Telegram (замена email)
- Интеграция Telegram Bot API
- "Мастер по установке" для регистрации
- Привязка людей из Telegram и с платформы

**Приоритет:** Средний (упрощение авторизации)

**Зависимости:** FP4 (текущая авторизация), FP9 (мастер установки)

---

### 📝 FP11: Content Submission & Admin Panel (todo)
**Что входит:**
- Система заявок на публикацию контента
- Ограничение: один пользователь = одна заявка за раз
- Минимальная админка для просмотра заявок
- Утверждение/отклонение заявок
- Анти-абуз политика

**Приоритет:** Высокий (контроль контента)

**Зависимости:** FP4 (пользователи), FP6 (админка)

---

### 📸 FP12: Photo & Video Gallery (todo)
**Что входит:**
- Загрузка фото с джемов
- Фотоальбомы (сортировка по джему/году)
- Видео архив
- Оптимизация загрузки медиа
- Поддержка разных форматов

**Приоритет:** Средний (медиа-контент)

**Зависимости:** FP7 (медиа просмотрщики), FP11 (загрузка)

---

### 🎨 FP13: Visual Style & Polish (todo)
**Что входит:**
- UI стиль "похож на Chicago95, но не он"
- Единая система UI-компонентов/иконок
- Палитра (выбор Антона)
- Иконки (рисунки Антона)
- Ретро-шрифты
- Тактильность интерфейса

**Приоритет:** Средний (визуальная идентичность)

**Зависимости:** FP4 (Windows 95 UI), FP6 (Desktop)

---

### 🚀 FP14: Performance & Optimization (todo)
**Что входит:**
- Оптимизация Window Manager (много окон)
- Кэширование контента
- Lazy loading
- Виртуальный скроллинг для Explorer
- Оптимизация медиа загрузки

**Приоритет:** Средний (производительность)

**Зависимости:** FP6, FP7, FP12

---

### 🔒 FP15: Security & Compliance (todo)
**Что входит:**
- Улучшение CSP политик
- Sandbox для iframe
- Защита от XSS/CSRF
- Резервное копирование
- Аудит логов

**Приоритет:** Высокий (безопасность)

**Зависимости:** FP3 (CSP), все предыдущие FP

## Приоритизация и этапы

### Этап 1: MVP Desktop (FP6 + FP7)
**Цель:** Рабочий Desktop с навигацией и просмотром контента

**FP:**
- FP6: Desktop Workspace & Window Manager
- FP7: Explorer & Media Viewers

**Выход:** Пользователь может открыть Desktop, кликнуть иконку, открыть окно, просмотреть игры/фото/видео

---

### Этап 2: Контент & Админка (FP11 + FP12)
**Цель:** Система заявок и медиа-архив

**FP:**
- FP11: Content Submission & Admin Panel
- FP12: Photo & Video Gallery

**Выход:** Пользователи могут подавать заявки, админы могут их обрабатывать, медиа загружается и просматривается

---

### Этап 3: Атмосфера & UX (FP8 + FP9 + FP13)
**Цель:** Атмосфера Windows93, регистрация на джемы

**FP:**
- FP8: "Безделушки" & Micro-interactions
- FP9: Jam Info & Registration Wizard
- FP13: Visual Style & Polish

**Выход:** Платформа выглядит и ощущается как Windows93, есть регистрация на джемы, есть развлечения

---

### Этап 4: Упрощение & Оптимизация (FP10 + FP14 + FP15)
**Цель:** Упрощение авторизации, производительность, безопасность

**FP:**
- FP10: Telegram Auth & Registration Wizard
- FP14: Performance & Optimization
- FP15: Security & Compliance

**Выход:** Telegram авторизация, оптимизированная производительность, безопасность

---

## Риски и митигации

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Window Manager сложность | Высокая | Высокое | Поэтапная реализация, прототипирование |
| Mobile режим UX | Средняя | Среднее | Тестирование на реальных устройствах |

| Производительность с многими окнами | Средняя | Среднее | Ограничение количества окон, оптимизация |
| Визуальный стиль субъективность | Средняя | Низкое | Итерации с дизайнером (Антон) |
