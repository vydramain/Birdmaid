# FP3.2: Explorer UX & Shell Window Maximize Fixes

**Status:** build (M7 gate REJECT)  
**Created:** 2025-02-22  
**Updated:** 2025-02-22  
**Supersedes:** FP3 patchset gaps (post-build issues)

> **Context:** Follow-up к FP3. Решает 10 выявленных UX/API/Shell issues: Explorer UI (roots, toolbar, scroll, back icon, multi-instance state), app-discovery (icon, 404 race), FS write (delete, rename path), Shell WindowManager (maximize).

---

## Problem Statement

После реализации FP3 выявлены проблемы:

1. **Explorer roots:** В корне "My Computer" отображается tile "Computer" — должен быть только список дисков (A:, C:, D:).
2. **Explorer scroll:** При большом количестве файлов скролл скрывает адресную строку и кнопку назад — они должны быть sticky.
3. **Explorer back:** Кнопка назад показывает текст вместо иконки-стрелки влево.
4. **App-discovery icon:** Папки с index.html внутри отображаются как folder — должны иметь иконку приложения.
5. **App open 404:** После загрузки zip-приложения первый open даёт 404; после refresh работает — race/consistency.
6. **Explorer multi-instance:** При смене фокуса между несколькими Explorer путь сбрасывается — должен сохраняться.
7. **Delete:** Операция удаления не отправляет запрос (UI event wiring / handler).
8. **Rename:** toPath формируется как nested path (cross-parent) вместо same-parent rename — баг в построении путей.
9. **Explorer roots toolbar:** В корне "My Computer" (экран дисков) не должно быть верхней панели (address bar + back) — только при входе в диск.
10. **Shell maximize:** Кнопка развернуть на весь экран не работает — окно должно занимать viewport, фиксировать размер, второй клик — restore.

### M4_APP_DISCOVERY_OPEN (A4: app icon, A5: no 404 race)

| Item             | Location                                              | Proof                                                               |
| ---------------- | ----------------------------------------------------- | ------------------------------------------------------------------- |
| fs-icon-app      | `front/shared/fs-tile.css`                            | `.fs-icon-app::before { content: "\1F4BB" }` — app dir icon         |
| Explorer icon    | `front/apps/explorer/main.ts`                         | `iconClass = item.isApp ? "fs-icon-app" : "fs-icon-folder"`         |
| Zip placeholder  | `front/apps/explorer/main.ts`                         | Placeholder uses `fs-icon-app` (isApp: true)                        |
| Shell retry      | `front/Shell.tsx`                                     | open-url: 3 attempts, 300ms delay on 404                            |
| Gateway retry    | `back/src/fs.ts` getOpenUrl                           | HeadObject: 3 attempts, 200ms delay on S3 NotFound                  |
| Integration T-A5 | `back/__tests__/fp3/api-fs-write.integration.test.ts` | upload-zip → list isApp → open-url 200                              |
| E2E T-A4         | `e2e/fp3-explorer.spec.ts`                            | sample-app tile has .fs-icon-app                                    |
| E2E T-A5-E2E     | `e2e/fp3-explorer.spec.ts`                            | upload zip → app icon → double click → app window (mocked open-url) |

**Why 404:** S3/MinIO eventual consistency — object may not be visible immediately after PutObject. HeadObject returns NotFound until storage propagates.

**Race fix:** (1) Gateway: getOpenUrl retries HeadObject 3× with 200ms backoff on NotFound. (2) Shell: handleShellOpen retries open-url fetch 3× with 300ms delay on 404. Either layer can recover from transient 404.

### M5_FS_WRITE (A7: delete, A8: rename toPath)

| Item             | Location                                              | Proof                                                                       |
| ---------------- | ----------------------------------------------------- | --------------------------------------------------------------------------- |
| dirname          | `front/apps/explorer/main.ts`                         | `dirname(fromPath)` = parent with trailing slash; toPath = parent + newName |
| commitRename     | `front/apps/explorer/main.ts`                         | toPath = dirname(fromPath) + newName [+ "/" if dir]                         |
| onDelete         | `front/apps/explorer/main.ts`                         | fetchWithToken DELETE; spinner; tile.remove on 204; revert + log on fail    |
| delete dir key   | `back/src/fs.ts`                                      | path.endsWith("/") → toS3Prefix (dir placeholder key)                       |
| Integration T-A7 | `back/__tests__/fp3/api-fs-write.integration.test.ts` | delete dir → 204, list → item gone                                          |
| Integration T-A8 | `back/__tests__/fp3/api-fs-write.integration.test.ts` | rename "Новая Папка 3" → "Новая Папка 343" (same parent)                    |
| E2E T-M6-D1      | `e2e/fp3-explorer.spec.ts`                            | Delete → mock 204 → tile gone                                               |

**Rename before:** `parentPath = item.path.replace(/\/[^/]+$/, "").replace(/([^/])$/, "$1/")` — wrong for dirs (e.g. `/.../Новая Папка 3/` → parent `/.../Новая Папка /`).

**Rename after:** `parentPath = dirname(fromPath)` — trimmed path, lastIndexOf("/"), slice(0, idx+1) → `/@root/DISK_C/My Documents/`.

**Delete:** Context menu → onDelete → fetchWithToken(DELETE, { path }) → 204 removes tile; 4xx/5xx restores label + log.
