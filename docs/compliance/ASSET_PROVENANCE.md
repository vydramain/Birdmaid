# Asset Provenance Registry

**Version:** 1.0  
**Created:** 2026-01-22  
**Purpose:** Track license and source information for all build assets  
**Status:** Active  
**Owner:** @Compliance

## Overview

This document tracks the provenance (source, license, redistributability) of every asset included in the build. Every file in `front/public/icons/**`, `front/public/fonts/**`, `front/public/cursors/**`, and `front/public/sounds/**` must have an entry here.

## Format

Each entry follows this format:

| Local Path | Source | License | Redistributable | Notes |
|------------|--------|---------|-----------------|-------|
| `path/to/file.ext` | Source URL or "Custom" | SPDX identifier | Yes/No | Additional notes |

## Adding New Assets

When adding a new asset:

1. **Verify license** is in the Allowed list (see `ASSET_POLICY.md`)
2. **Add entry** to this table with:
   - Full local path relative to `front/public/`
   - Source URL or "Custom"
   - SPDX license identifier
   - Redistributable: Yes/No
   - Notes (author, date, purpose)
3. **Run check:** `node scripts/check-asset-provenance.cjs`
4. **Commit** both the asset and this file

## License Verification

- **MIT:** Check for `LICENSE` or `LICENSE.txt` file in source
- **OFL:** Check for `OFL.txt` file in font package
- **CC0:** Check for explicit CC0 declaration
- **Custom:** Document author and creation date
