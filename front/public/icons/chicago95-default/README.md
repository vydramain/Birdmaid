# Chicago95 Default Icon Theme

Placeholder icon theme for Chicago95 style.

## Structure

```
chicago95-default/
├── 16x16/  # 16x16px icons
├── 32x32/  # 32x32px icons
└── 48x48/  # 48x48px icons
```

## Icon Types

Each size folder should contain PNG files named after IconType:
- `file.png`, `dir.png`, `link.png`
- `file-txt.png`, `file-md.png`, etc.
- `app-explorer.png`, `app-notepad.png`, etc.
- `system-user.png`, `system-computer.png`
- `unknown.png` (fallback)
