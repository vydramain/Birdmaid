# Legacy Tests

Эти тесты были перемещены в legacy во время Phase 1: Cleanup (M0) - FP7 v2.

## Причина перемещения

Эти тесты тестируют старую архитектуру с react-router маршрутами и сайт-страницами, которые противоречат shell-only контракту (FP7 v2, Product Surface Contract).

## Что здесь

- Тесты для старых endpoints и функциональности
- Тесты для email/password auth (будут удалены после реализации Telegram auth в Phase 2)

## Миграция

Эти тесты можно использовать как референс при миграции функциональности в shell-only модель, но они не должны запускаться в CI/CD, так как тестируют удаленный код.
